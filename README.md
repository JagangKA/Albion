# Albion — сканер крафта и Чёрного рынка

Показывает, что прямо сейчас выгодно скрафтить в Albion Online и продать —
на Чёрном рынке в Кэрлеоне или прямо в городе, без поездок.

**Сайт:** https://jagangka.github.io/Albion/

Не калькулятор, а сканер: не нужно выбирать предмет и вводить цены руками.
Он сам перебирает больше четырёх тысяч позиций по семи рынкам и выдаёт готовый
список — с себестоимостью, размером партии под твой бюджет и расходом фокуса.
Покрытие полное, без урезанной бесплатной версии.

Кроме крафта есть ещё два инструмента:

* **флиппинг** — купить готовую вещь у игрока дёшево в городе и перепродать
  на Чёрном рынке, без крафта вообще;
* **план на бюджет** — не одна позиция под весь кошелёк, а сразу несколько:
  бюджет распределяется по нескольким позициям за раз, с оглядкой на то,
  сколько рынок способен переварить за выбранный срок.

У каждой позиции в таблицах крафта и флиппинга — мини-график цены за
последнюю неделю (наводишь — видно цифры). Строится из тех же данных, что
уже тянутся для проверки объёмов, лишних запросов к API не добавляет.

Плюс **каталог** — цена любого предмета без фильтра по прибыли, когда нужно
просто узнать, сколько что стоит.

В таблице крафта — поиск по названию, сортировка (по прибыли / марже /
себестоимости) и два независимых фильтра: по категории (снаряжение /
переработка / расходники) и по типу вещи (меч, латный шлем, эликсир и так
далее — 31 тип из игровых данных). Покрытие включает оружие, броню, маунтов,
еду и эликсиры.

## Чем отличается от других инструментов

Большинство калькуляторов берут минимальную цену ордера как есть. На живых
данных это регулярно врёт, и мы отдельно с этим боремся:

* **Ордера-мечты.** На Чёрном рынке встречается вещь, выставленная за 2 299 999,
  когда рынок реально берёт её по 196 000. Цены в режиме ожидания сверяются
  со средней ценой фактических сделок за неделю и прижимаются к ней.
* **Тонкие ордера на закупке.** Руны стоят в ордере 7 серебра при средней цене
  сделок 29 и обороте в миллионы штук за сутки — по такой цене там лежит пара
  штук. Себестоимость считается по честной цене, а не по витрине.
* **Объёмы.** Датасет не показывает, сколько единиц лежит в ордере, поэтому
  ёмкость рынка оценивается по истории торгов: и спрос в точке сбыта,
  и наличие материалов в городе закупки.
* **Фокус — расходуемый ресурс.** Партия из 180 вещей может съесть восемь дней
  накопления фокуса, и в таблице это видно сразу.
* **Артефакты из рун исключены.** По игровому дампу выходит «50 рун → артефакт»
  с маржой в тысячи процентов, чего в игре быть не может. Модель неполная,
  выдавать её за заработок нельзя.
* **Дев-предметы и квестовый инвентарь отфильтрованы.** В дампе попадаются
  тестовые записи разработчиков и неизданные прототипы — 329 таких найдено
  и исключено. Отдельная ловушка — квестовые предметы (тюки каравана и
  подобное): у них может найтись обычная цена на обычный ресурс в рецепте,
  из-за чего расчёт по цене их не отсеет, хотя продать такое на рынке нельзя
  в принципе. Пришлось исключать по префиксу id, а не по цене.

## Как это работает

```
GitHub Actions раз в час → build.py считает → docs/index.json + docs/mode-*.json
                                                   ↓
                       GitHub Pages отдаёт страницу, браузер фильтрует под бюджет
```

Сервер не нужен: сайт статический, а бюджет, фокус и место сбыта применяются
прямо в браузере.

* цены — [Albion Online Data Project](https://www.albion-online-data.com/);
* рецепты, возврат материалов и пути зачарования — из игровых дампов
  [ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps).

## Запуск у себя

```bash
python build.py     # посчитать и записать docs/index.json + docs/mode-*.json
python app.py       # локальная версия с автообновлением (открывается в браузере)
python scan.py      # быстрый прогон в консоли
```

Настройки — в `config.json`: сервер (`europe` / `west` / `east`), премиум,
бонус города к возврату, пороги отбора.

Локальная версия удобнее публичной: данные свежие лично для тебя,
без часовой задержки.

## Чему нельзя верить вслепую

Цены собирают сами игроки своим клиентом, поэтому они бывают устаревшими,
а по редким позициям их может не быть вовсе. Знак `?` в таблице означает,
что объём по части материалов не подтверждён, `*` — что цену пришлось прижать
к реальным сделкам.

Перед крупной закупкой сверься с рынком в игре. И помни: скупая большие объёмы,
ты сам двигаешь цену вверх.
